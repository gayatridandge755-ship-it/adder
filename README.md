 # 32-Bit Ripple Carry Adder

## Description
A 32-bit ripple carry adder designed using Verilog in Vivado.

## Design
The adder uses 32 Full Adders connected through a carry chain.

## Verilog Concepts Used
- Module and ports
- Half Adder
- Full Adder
- Wire
- Generate block
- For loop
- Continuous assignment

## Tools
- AMD Vivado
- Verilog HDL

## Output
The design produces a 33-bit result, including the final carry.
